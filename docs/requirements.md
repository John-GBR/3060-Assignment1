User stories:

As a new PhD student, I want somewhere where I can easily learn about the MSR research group so that I feel less overwhelmed when joining the research group.

As a group lead, I want the site to be split into different sections for Data Sources, Collection Methods, Analysis Methods, and Publication Venues so that the website is well organized.

As a user of the site, I want to be able to switch between sections with tabs or buttons so that the website is easy to navigate.

As a user of the site, I want each section of the site to contain content pertaining to said section's subject so that I can easily find & learn important info & details about each subject.

As a group lead, I want the site to have some styling such that it doesn't look old fashioned.
