Data sources:

  • Github:
    • A cloud-based web platform that lets developers store, manage, and collaborate on code using a version control system called Git.
    • Data it provides: repositories, commits, pull requests, issues, stars
  • Stack Overflow:
    • A commonly used Q & A website for programmers.
    • Data it provides: questions, answers, tags, user reputation
  • JIRA:
    • A web-based AI-powered project and issue-tracking software.
    • Data it provides: issue tracking, sprint data, bug reports
  • App Stores:
    • Digital marketplaces where users can browse, purchase, download, & update software apps for smart devices.
    • Data it provides: Google Play and Apple App Store reviews, ratings, downloads
  • Travis CI / Jenkins:
    • Commonly used CI / CD tools.
    • Data it provides: build logs, test results, deployment data
  • Mailing Lists:
    • Collections of email addresses used to send info to multiple recipients at the same time using a single address.
    • Data it provides: developer discussions, archives
  • npm Registry:
    • An online database that stores JavaScript packages, software modules, and their corresponding metadata.
    • Data it provides: package dependencies, downloads, versions
